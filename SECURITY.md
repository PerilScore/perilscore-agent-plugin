# Security policy

Please report suspected vulnerabilities privately to
[info@perilscore.com](mailto:info@perilscore.com). Do not open a public
issue with credentials, customer addresses, OAuth codes, access tokens, API
keys, or reproducible customer-data access.

Include the affected component, impact, reproduction steps with sensitive data
removed, and a safe way to contact you. PerilScore will acknowledge the report,
investigate it, and coordinate remediation and disclosure where appropriate.

The plugin itself contains configuration and Markdown guidance only. It does
not ship executable hooks, binaries, install scripts, or telemetry. Its declared
network endpoint is `https://app.perilscore.com/mcp`.
